Hoe werkt het?

De identificatiecode wordt als bits verdeeld over RGB-waarden van verschillende pixels. Per kleurkanaal wordt maximaal één waarde aangepast.

Hierdoor wordt de afbeelding normaal gesproken niet zichtbaar veranderd. Het controleprogramma gebruikt hetzelfde patroon om de code later terug te vinden.

Gebruik voor deze prototypeversie PNG. JPEG-compressie kan de verborgen informatie veranderen.
